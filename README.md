## 📖 About this repository

This repository contains the **official website** for my Visual Studio Code extensions: a bilingual (EN/ES) landing page with light/dark theme support, built with plain HTML, CSS and JavaScript — no frameworks, no dependencies, fast to load.

The site showcases five independent tools, each focused on solving a concrete problem in the editor workflow.

## 🧩 Projects

| Extension | Description | Install |
|---|---|---|
| 🎨 **Pro VSCode Themes** | Carefully crafted color themes for long coding sessions without eye strain. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-themes) |
| 🤖 **Pro AI Assistant** | AI assistance built into the editor to explain, refactor and document code. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-ai) |

## ✨ Why use these extensions

- ⚡ **Easy to use** — install and start working right away, no complex setup.
- 🚀 **Fast and lightweight** — built to not affect editor performance, even on large projects.
- 🔒 **Privacy first** — everything runs locally whenever possible.

## 🛠️ Site stack

- Semantic HTML5
- Plain CSS (`style.css`) with light/dark theme support
- Vanilla JavaScript (`script.js`) for i18n (EN/ES), animations and theme toggle
- No frameworks or external dependencies

### Run locally

```bash
git clone https://github.com/alvarosiles/vscode.git
cd vscode
# Open index.html in your browser, or serve the folder:
npx serve .
```

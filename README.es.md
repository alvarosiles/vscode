## 📖 Sobre este repositorio

Este repositorio contiene el **sitio web oficial** de mis extensiones para Visual Studio Code: una landing page bilingüe (ES/EN), con tema claro/oscuro, construida en HTML, CSS y JavaScript puro — sin frameworks, sin dependencias, rápida de cargar.

El sitio presenta cinco herramientas independientes, cada una enfocada en resolver un problema concreto del flujo de trabajo en el editor.

## 🧩 Proyectos

| Extensión | Descripción | Instalar |
|---|---|---|
| 🎨 **Pro VSCode Themes** | Temas de color cuidados al detalle para largas sesiones de código sin fatiga visual. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-themes) |
| 🤖 **Pro AI Assistant** | Asistencia con IA integrada en el editor para explicar, refactorizar y documentar código. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-ai) |
| 🔧 **Pro VSCode Tools** | Utilidades del día a día: formateo rápido, atajos de navegación y automatización de tareas. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-tools) |
| ✂️ **Pro VSCode Snippets** | Snippets curados para los lenguajes y frameworks más usados. | [Marketplace](https://marketplace.visualstudio.com/items?itemName=alvarosiles.pro-vscode-snippets) |

## ✨ Por qué usar estas extensiones

- ⚡ **Fácil de usar** — instala y empieza a trabajar de inmediato, sin configuraciones complejas.
- 🚀 **Rápido y ligero** — diseñadas para no afectar el rendimiento del editor, incluso en proyectos grandes.
- 🔒 **Privacidad primero** — todo funciona localmente cuando es posible.

## 🛠️ Stack del sitio

- HTML5 semántico
- CSS puro (`style.css`) con soporte de tema claro/oscuro
- JavaScript vanilla (`script.js`) para i18n (ES/EN), animaciones y toggle de tema
- Sin frameworks ni dependencias externas

### Ejecutar localmente

```bash
git clone https://github.com/alvarosiles/vscode.git
cd vscode
# Abre index.html en tu navegador, o sirve la carpeta:
npx serve .
```
